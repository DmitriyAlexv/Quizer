## Общая информация

- **Базовый URL:** `http://localhost:<port>/api/v1`
- **Формат данных:** JSON
- **Версия API:** `v1`
- **Документация Swagger:** доступна по адресу `/swagger` (в среде разработки).

Все эндпоинты, кроме `POST /api/v1/users/register` и `POST /api/v1/users/authorize`, требуют аутентификации.

---

## Аутентификация

Аутентификация реализована через **JWT Bearer Token**.

Для доступа к защищённым эндпоинтам необходимо передавать токен в заголовке:

```
Authorization: Bearer <token>
```

Токен получается при вызове `POST /api/v1/users/authorize`.

## Коды ошибок

| HTTP-код | Описание |
|----------|----------|
| `200 OK` | Успешное выполнение |
| `201 Created` | Ресурс успешно создан |
| `204 No Content` | Успешное выполнение без тела ответа |
| `400 Bad Request` | Некорректные данные запроса (ошибка валидации) |
| `401 Unauthorized` | Пользователь не авторизован / неверные учётные данные |
| `403 Forbidden` | Нет прав на выполнение операции (не владелец) |
| `404 Not Found` | Ресурс не найден |
| `409 Conflict` | Конфликт состояния (например, квиз опубликован, попытка завершена) |
| `500 Internal Server Error` | Внутренняя ошибка сервера |

## Общие структуры данных

### Перечисления

**`QuizStatus`** — статус квиза:

| Значение | Описание |
|----------|----------|
| `Draft` | Черновик (можно редактировать) |
| `Published` | Опубликован (доступен для прохождения) |

**`QuestionType`** — тип вопроса:

| Значение | Описание |
|----------|----------|
| `Open` | Открытый ответ (текст) |
| `SingleChoice` | Одиночный выбор |
| `MultipleChoice` | Множественный выбор |

**`AttemptStatus`** — статус попытки:

| Значение | Описание |
|----------|----------|
| `InProgress` | В процессе прохождения |
| `Completed` | Завершена |

### `PagedResponse<T>` — ответ с пагинацией

```json
{
  "items": [],
  "totalCount": 0,
  "page": 1,
  "pageSize": 10,
  "totalPages": 0,
  "hasPreviousPage": false,
  "hasNextPage": false
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `items` | `T[]` | Коллекция элементов текущей страницы |
| `totalCount` | `int` | Общее количество элементов |
| `page` | `int` | Номер текущей страницы (начиная с 1) |
| `pageSize` | `int` | Количество элементов на странице |
| `totalPages` | `int` | Общее количество страниц |
| `hasPreviousPage` | `bool` | Существует ли предыдущая страница |
| `hasNextPage` | `bool` | Существует ли следующая страница |

## Пользователи

### 1. Регистрация пользователя

**`POST /api/v1/users/register`**

**Аутентификация:** не требуется.

**Тело запроса:**

```json
{
  "email": "user@example.com",
  "password": "Password123!",
  "name": "Иван Иванов"
}
```

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `email` | `string` | Да | Электронная почта пользователя |
| `password` | `string` | Да | Пароль пользователя |
| `name` | `string` | Да | Имя пользователя |

**Успешный ответ — `200 OK`:**

```json
"3fa85f64-5717-4562-b3fc-2c963f66afa6"
```

Тело ответа — идентификатор созданного пользователя (GUID).

**Коды ошибок:**

| Код | Описание |
|-----|----------|
| `400 Bad Request` | Некорректные данные запроса |
| `409 Conflict` | Пользователь с таким email уже существует |
